# VertivEra
VertivEra is an all-in-one township waste management and community platform built for Sime Darby Property. Born from residents' firsthand frustration with illegal dumping, clogged drains, and fragmented recycling options, VertivEra connects neighborhood communities directly with township operations. It features an interactive recycling bin map, a geotagged hazard reporting system for issues like blocked monsoon drains, and a one-click scheduling tool for doorstep bulky waste pickups (like old furniture and appliances). To encourage local reuse, it also includes ReMarket, a neighborhood marketplace moderated by basic AI vision models to ensure safe, quality listings. By integrating resident tools with a central dashboard for property managers, VertivEra turns reactive cleanup into organized, practical township care without requiring expensive hardware updates.
